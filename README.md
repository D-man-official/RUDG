# 🌟 About RUDG

> **Raiganj University Developers Group (RUDG)** is a student-led tech community built by the students of **DCIS, Raiganj University** to create a culture of innovation, collaboration, and practical learning.

We aim to help students explore modern technologies beyond classrooms through:

✨ Workshops  
✨ Hackathons  
✨ AI & Emerging Technologies  
✨ Web & App Development  
✨ Open Source  
✨ Networking & Collaboration  

---

# 🎯 Our Mission

To empower students with practical technical skills, innovation mindset, teamwork, and industry exposure while building one of the strongest student tech communities in Raiganj University.
