## 🚀 About RUDG

**Raiganj University Developers Group (RUDG)** is a student-driven tech community focused on helping students grow beyond classroom learning through:

- 💻 Web Development
- 🤖 AI Tools & Machine Learning
- 🏆 Hackathons
- 🌐 Open Source
- 📱 App Development
- 🎨 UI/UX Design
- 🔐 Cybersecurity
- 🤝 Networking & Collaboration

Our mission is to create a strong developer culture inside Raiganj University by organizing workshops, events, bootcamps, and collaborative learning opportunities.

---

## 🎯 Vision

To build a strong and innovative tech ecosystem inside Raiganj University where students can learn, collaborate, and grow together.
